## 📌 Portfolio Overview
This repository compiles four end-to-end Earth Observation (EO) case studies applying **Google Earth Engine (GEE)** and **QGIS** to analyze critical environmental and socio-economic transformations across Nigeria. 

The portfolio bridges multi-sensor remote sensing methodologies—ranging from **Nighttime Light (NTL) urban footprint tracking** to **MODIS/ERA5 climate parameter extraction** and **high-resolution crop health monitoring**.

## 🔬 Core Technical Competencies
* **Multi-Sensor Data Fusion:** Processing optical (Sentinel-2/Landsat), night-lights (VIIRS), and climate reanalysis datasets (ERA5/CHIRPS).
* **Time-Series Analysis:** Extracting regional sum radiance, calculating seasonal NDVI anomalies, and filtering atmospheric noise (e.g., monsoon cloud cover and Harmattan haze).
* **Cartographic Execution:** Advanced pseudo-color rendering, bitwise spatial classification, and custom GIS layout design.
